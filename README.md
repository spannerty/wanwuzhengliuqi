# 万物蒸馏器

把一个人留在聊天记录里的样子，重新叫醒。

---

我们这辈子，会和很多人说话。

可有些人，说着说着，就不在了。

不是不说了——是再也没法说了。
那个总爱毒舌损你的老友，去了另一座城市，渐渐没了音讯；
那个陪你熬过无数深夜的人，成了"前任"，对话框停在了去年某天；
那个教你很多、却突然联系不上的前辈……

你回头想：他到底是怎么说话的来着？

那些口头禅，那些停顿，那些只在深夜才蹦出来的字，
不知道什么时候，就散在对话框的缝隙里了。
你以为永远记得，其实忘得比想象中快。

这个东西，想替你把那些"怎么说话"的样子，留下来。

传一段聊天记录进来，它认出里面那个人，
把他的语气、节奏、口头禅，连吐槽时的那点小脾气，
一点点蒸馏出来——

然后，你就有了一个随时能聊的"他"。

他不累，不失忆，不会聊着聊着突然变成另一个人。
你换了设备、隔了几个月再回来，他还是那个语气。

更妙的是：你们还能接着聊。
今天发生的事，你讲给他听；明天你又来了。
这些新的对话，只存在于你们之间——
是现实里再也没机会留下的、新的"赛博记忆"。

> 这不是复活，也不是替代。只是给想念，留一个还能说话的地方。

## 它能做什么

- **认人**：贴一段聊天记录，自动找出里面所有说话的人。你点一个，就蒸馏一个。
- **像**：不是套几个关键词。是把一个人的"语言指纹"抽出来——一句话多长、爱用什么词、什么时候该回那个"[捂脸]"。
- **记得你，也记得他**：聊过的它都记着，包括你们之间那些只有彼此懂的事。下次见面，不会重复问"你是谁""你刚说啥"，也不会忘了他是谁、你们聊过什么。
- **会主动**：你 idle 久了，他会自己冒出来一句，像真朋友那样，不刷屏，只是"在吗"。
- **有脾气**：你烦躁，他甩你一个"[衰]"；你兴奋，他回你"[666]"；深夜他放慢节奏，甚至不回——和真人一样，有作息。
- **会分享**：偶尔丢一条真·新闻链接过来，后面跟一句他的点评，像他真的刚刷到。
- **长这样**：界面就是微信的样子。聊起来，不像在测一个机器人。
- **换上头像**：「··· → 头像设置」里，给你和他各传一张头像，聊起来更像一个真实的人。

## 为什么叫"万物蒸馏器"

名字有点贪心。

聊天风格，只是第一样被蒸馏的东西。
往后也许能蒸馏一段旋律、一种笔触、一段日子留下的气味。

先从"一个人怎么说话"开始吧——因为有些声音，我们怕自己忘了。

## 怎么用

1. 打开 `万物蒸馏器.html`——双击就行，不用装任何东西。
2. 点左下角「＋」，上传或粘贴一段聊天记录。
3. 选你要复刻的那个人，点「开始蒸馏」。
4. 然后，就像加了他微信一样，聊。聊今天，也聊那些他不在的日子里发生的事。

想更"像"一点，在右上角「··· → 接口设置」里填一个 OpenAI 兼容的接口；
不填也没关系，它会用内置的离线风格兜底，照样能接话。

## 关于你的记录

所有东西，都只存在你自己的浏览器里。

聊天记录不上传任何服务器，分身也不会被谁看见。
它属于你，也只属于你。
你们后来聊的那些新对话，谁也看不到，只留在你这儿。

## 一句多余的话

做这个，是因为有些人，我们以为永远会在列表里，
结果某天点开，最后一条消息停在一个很普通的下午。

我们没法让谁回来。
但如果哪天你想说说今天的事，又找不到那个对话框了——
这里，还留着他说话的语气。

你可以继续跟他聊。
聊新的日常，聊你后来去了哪里，聊那些他没来得及参与的日子。
这些对话不会发给任何人，只留在你这儿，
成为只属于你们俩的、新的记忆。

如果它能让某个想说话的夜晚，
你又听见了那个熟悉的语气——
那这点代码，就没白写。
